# Lab 03 - OOP nâng cao

Lê Tuấn Quang - 24000641

10 bài về kế thừa, `base`, `virtual/override`, lớp trừu tượng và interface.
Có menu chọn bài, dữ liệu mẫu và quản lý nhiều hệ sinh viên.

Mở `Lab03_OOPAdvanced.sln` bằng Visual Studio 2022 có hỗ trợ .NET 8,
nhấn Ctrl + F5. Hoặc chạy tại thư mục project:

```sh
dotnet run
dotnet run -- --test
```

Nếu chạy từ thư mục gốc repo:

```sh
dotnet run --project Lab03_OOPAdvanced
```
