# IT3212 - Lập trình .NET

Bài thực hành môn Lập trình .NET. Mỗi lab để trong một project riêng.

## Các bài đã làm

- [Lab 01 - Console C#](Lab01_Console/README.md): 10 bài nhập xuất,
  điều kiện, vòng lặp và xử lý ngoại lệ.

## Cách chạy

Cài .NET SDK phù hợp với project (Lab01 dùng .NET 10).
Mở `IT3212_Labs.sln` bằng Visual Studio, chọn project cần chạy làm
Startup Project rồi nhấn Ctrl + F5.

Hướng dẫn chi tiết, dữ liệu thử và báo cáo nằm trong thư mục từng lab.
