# Lab 01 - Console C#

## Nội dung

1. Nhập thông tin cá nhân, tính tuổi gần đúng.
2. Tính diện tích xung quanh và thể tích hình trụ.
3. Xếp loại kết quả học tập.
4. Menu tính tổng và bảng cửu chương.
5. Xử lý ngoại lệ phép chia.
6. Giải phương trình bậc hai.
7. Thống kê dãy số.
8. In số nguyên tố không vượt quá n.
9. Đọc số từ 0 đến 99.
10. Vẽ tam giác và hình vuông bằng dấu `*`.

## Cách chạy

Cần .NET SDK 10. Mở [IT3212_Labs.sln](../IT3212_Labs.sln) bằng
Visual Studio hỗ trợ .NET 10, chọn `Lab01_Console` làm Startup Project
rồi nhấn Ctrl + F5.

Mở terminal tại thư mục `Lab01_Console` rồi chạy:

```sh
dotnet run
```

Nếu đang ở thư mục gốc repo, dùng `dotnet run --project Lab01_Console`.
Chọn bài từ 1 đến 10. Chọn 0 để thoát hoặc quay lại menu chính.
