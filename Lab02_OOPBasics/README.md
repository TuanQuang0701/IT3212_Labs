# Lab 02 - OOP cơ bản

Lê Tuấn Quang - 24000641

Gồm 10 bài: lớp sinh viên, constructor, đóng gói, tính tuổi và xếp loại,
danh sách sinh viên, sản phẩm, tài khoản ngân hàng, nhân viên, hình chữ nhật
và menu quản lý sinh viên.

## Chạy bài

Cài .NET SDK 10, mở terminal tại thư mục solution:

```sh
dotnet run --project Lab02_OOPBasics
```

Trong Visual Studio, mở `IT3212_Labs.sln`, chọn `Lab02_OOPBasics` làm
Startup Project rồi nhấn Ctrl + F5.

Chọn 1–10 để chạy bài, 0 để thoát. Bài 10 có thêm, sửa, xóa, tìm mã,
sắp xếp và thống kê. Có sẵn 5 sinh viên. Dữ liệu chỉ lưu trong bộ nhớ.

## Kiểm tra

```sh
dotnet run --project Lab02_OOPBasics -- --test
```
