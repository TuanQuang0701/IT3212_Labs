# Lab 04 - Windows Forms cơ bản

Lê Tuấn Quang - 24000641

10 bài WinForms, target **.NET Framework 4.8**, dùng Visual Studio 2022
với workload **.NET desktop development** và targeting pack 4.8.

Mở `Lab04_WinFormsBasic.sln`, nhấn Ctrl + F5. Màn hình chính có 10 nút
chọn bài. Bài 1–5 cùng hoàn thiện Form sinh viên; bài 6–10 có Form riêng.

```sh
dotnet build Lab04_WinFormsBasic.csproj -c Release
```

Form được bố trí bằng code C#; đọc và sửa control ngay trong file Form.
Ảnh mẫu ở `Images`, tự chép sang thư mục chạy khi build.
