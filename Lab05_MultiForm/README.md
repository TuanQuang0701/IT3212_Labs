# Lab05 - Sự kiện và ứng dụng đa Form

Lê Tuấn Quang - 24000641

WinForms .NET Framework 4.8, gồm 10 nội dung trong đề Lab05:
ErrorProvider, KeyPress, TextChanged, truyền đối tượng, menu MDI,
giới hạn đăng nhập, hộp thoại tìm kiếm/chọn khoa, xác nhận thoát và dashboard.

Mở `Lab05_MultiForm.sln` bằng Visual Studio có .NET desktop development
và targeting pack 4.8, nhấn Ctrl + F5. Chọn Form `.cs` → Shift + F7 để xem Designer.

```sh
dotnet build Lab05_MultiForm.csproj -c Release
```
